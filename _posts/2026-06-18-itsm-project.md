## 📌 프로젝트 소개

본 프로젝트는 기업 내부 ITSM(IT Service Management) 시스템의 운영 및 유지보수를 담당하며 사용자 요청사항을 반영한 기능 개선과 데이터 검증 업무를 수행한 프로젝트입니다.

ITSM 시스템의 기능 개선 및 유지보수 업무를 수행하며 사용자 요구사항을 분석하고, 기능 수정에 따른 영향 범위를 검토하며 개발을 진행하였습니다. 또한 Oracle SQL을 활용한 데이터 검증을 통해 기능의 정확성과 데이터 정합성을 확인하였습니다.

## 🛠 담당 업무

### 1. 공지사항 기능 개선

#### 개선 배경

사용자들이 공지사항 조회 시 일부 데이터가 정상적으로 표시되지 않는 문제가 발생하였습니다.

#### 수행 내용

* 공지사항 등록 기능 점검
* 조회 SQL 검토 및 수정
* 화면 UI 개선
* 데이터 조회 성능 확인

#### 결과

* 조회 오류 해결
* 사용자 편의성 향상
* 운영 문의 감소

---

### 2. 결재 프로세스 기능 수정

#### 문제 상황

특정 결재 상태에서 승인 및 반려 처리 과정 중 데이터가 정상적으로 갱신되지 않는 현상이 발생하였습니다.

#### 수행 내용

* 결재 상태별 로직 분석
* 승인/반려 프로세스 점검
* JSP 화면 수정
* Oracle 데이터 검증

#### 결과

* 결재 처리 오류 개선
* 업무 프로세스 안정화
* 운영 이슈 감소

---

### 3. 데이터 검증 및 운영 지원

#### 수행 내용

* Oracle SQL 데이터 조회
* 운영 데이터 정합성 확인
* 사용자 문의 대응
* 배포 후 기능 검증

#### 사용 SQL 예시

```sql
SELECT *
FROM TB_NOTICE
WHERE USE_YN = 'Y'
ORDER BY REG_DT DESC;
```

#### 경험한 점

운영 환경에서는 단순히 기능 구현보다 데이터의 정확성과 서비스 안정성이 중요하다는 것을 경험할 수 있었습니다.

## 💡 트러블 슈팅

### 데이터 조회 누락 현상

#### 문제

일부 공지사항이 목록에 표시되지 않는 현상 발생

#### 원인

조회 조건에 사용되는 상태값이 실제 데이터와 일치하지 않음

#### 해결

조회 SQL 수정 및 데이터 검증 수행

```sql
WHERE STATUS_CD = '01'
```

↓

```sql
WHERE STATUS_CD IN ('01', '02')
```

#### 결과

누락 데이터 정상 조회
